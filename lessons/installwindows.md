
# Installing software on Windows:
 
## Installing VSCode: 
- Go to https://code.visualstudio.com/
- It should automatically detect your OS and give you a download link.
- You can also go to https://code.visualstudio.com/#alt-downloads and chose from there.
- 
## Installing R:
*Please make sure you install the latest version of R (R version 4.6.1).*
- Go to [CRAN](http://cran.r-project.org/)
- Click on `Download R for Windows`
- Click on `base`
- Click on `Download R 4.6.1 for Windows`
- Open and run the executable file `R-4.6.1-win.exe`

## Installing RStudio:
- Go to http://www.rstudio.com/
- Click on `Download` and then select the `Rstudio Desktop` option 
- Download the installer for Windows `RStudio XXX - Windows Vista/7/8/10`
- Open and run the executable file 

## Installing Python: 
- Go to and select your version https://www.python.org/downloads/windows/
- Or, through VSCode
